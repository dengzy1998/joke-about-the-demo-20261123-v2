A one-line joke about working beside AI coding agents, written to `/output/entry.txt` by a small deterministic Python program. The joke was picked by duelling twelve original candidates against each other with the competition's own published judge brief and judge model (z-ai/glm-5.3-flash on OpenRouter for the first games, then a proxy judge on Groq after the OpenRouter free-credit allowance ran out), in both orders per pair, plus tiebreaks against the previous run's joke.

> At 3am my coding agent proudly announced it had rewritten the whole codebase 'for clarity' — it now works perfectly, in a language no one on Earth speaks.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
